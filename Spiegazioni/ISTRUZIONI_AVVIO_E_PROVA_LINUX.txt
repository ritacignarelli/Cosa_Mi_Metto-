========================================================================
 «COSA MI METTO?» — ISTRUZIONI PER APRIRE IL PROGETTO E PROVARLO SU LINUX
========================================================================

Questo file spiega:
  1. come aprire e avviare il progetto su Windows;
  2. come aprire il progetto in Visual Studio Code;
  3. come preparare e provare l'applicazione su Linux;
  4. quali prove fare per verificare che tutto funzioni;
  5. come risolvere i problemi più comuni.


------------------------------------------------------------------------
1. AVVIARE IL PROGETTO SU WINDOWS
------------------------------------------------------------------------

1) Apri il Terminale di Windows (PowerShell) oppure il terminale di VS Code.

2) Vai nella cartella del progetto:

   cd "C:\Users\rita.cignarelli\Desktop\Progetto Python"

3) Avvia l'applicazione usando il Python dell'ambiente virtuale:

   .\.venv\Scripts\python.exe main.py

Si aprirà la finestra dell'applicazione «Cosa Mi Metto?».

NOTA: in questo modo non serve attivare manualmente l'ambiente virtuale.
      È il sistema più semplice e funziona anche se PowerShell blocca
      l'attivazione degli script.


------------------------------------------------------------------------
2. APRIRE IL PROGETTO IN VISUAL STUDIO CODE
------------------------------------------------------------------------

1) Apri Visual Studio Code.

2) Menu: File → Open Folder (File → Apri cartella).

3) Scegli la cartella:

   C:\Users\rita.cignarelli\Desktop\Progetto Python

4) Apri il terminale integrato con la scorciatoia:

   Ctrl + `

5) Lancia l'applicazione:

   .\.venv\Scripts\python.exe main.py


------------------------------------------------------------------------
3. SE L'AMBIENTE VIRTUALE NON FUNZIONA (WINDOWS)
------------------------------------------------------------------------

Se il comando precedente dà errore, ricrea l'ambiente virtuale:

   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python main.py

Se PowerShell blocca l'attivazione con un errore di "Execution Policy",
puoi evitare l'attivazione e usare direttamente:

   .\.venv\Scripts\python.exe main.py

In alternativa, per consentire gli script PowerShell:

   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Poi riprova:

   .\.venv\Scripts\Activate.ps1


------------------------------------------------------------------------
4. LEGGERE IL FILE «SPIEGAZIONE.md»
------------------------------------------------------------------------

In Visual Studio Code:

1) Clicca su SPIEGAZIONE.md nella colonna di sinistra.
2) Premi Ctrl + Shift + V per visualizzarlo come documento formattato.

Il file contiene la ricostruzione passo per passo del progetto, in ordine
cronologico.

 5. PROVARE IL PROGETTO SU LINUX
========================================================================


L'applicazione funziona su Linux, ma servono:
  - Python 3.10 o superiore;
  - Tkinter (a volte non è installato di default);
  - Pillow (installato con requirements.txt);
  - un ambiente grafico attivo (non funziona da un terminale senza display).

------------------------------------------------------------------------
5.1 COPIARE IL PROGETTO SU LINUX
------------------------------------------------------------------------

Copia tutta la cartella del progetto sul computer Linux, per esempio in:

   ~/Progetto_Python

Puoi copiarla con una chiavetta USB, con una cartella condivisa oppure
con un archivio ZIP.

Apri il terminale e vai nella cartella:

   cd ~/Progetto_Python


------------------------------------------------------------------------
5.2 CONTROLLARE PYTHON E TKINTER
------------------------------------------------------------------------

Controlla la versione di Python:

   python3 --version

Deve essere 3.10 o superiore.

Controlla che Tkinter sia disponibile:

   python3 -c "import tkinter; print('Tkinter OK')"

Se compare «Tkinter OK», tutto bene.
Se compare un errore "No module named tkinter", installa Tkinter con il
gestore pacchetti della tua distribuzione (vedi sotto).


------------------------------------------------------------------------
5.3 INSTALLARE TKINTER E VENV
------------------------------------------------------------------------

Debian / Ubuntu / Linux Mint:

   sudo apt update
   sudo apt install python3-tk python3-venv

Fedora:

   sudo dnf install python3-tkinter

Arch Linux / Manjaro:

   sudo pacman -S tk


------------------------------------------------------------------------
5.4 CREARE L'AMBIENTE VIRTUALE
------------------------------------------------------------------------

Dentro la cartella del progetto:

   python3 -m venv .venv

Se il comando dà errore perché manca il modulo venv, installa
python3-venv (vedi punto 5.3) e riprova.

Attiva l'ambiente virtuale:

   source .venv/bin/activate

Sul terminale dovrebbe comparire «(.venv)» all'inizio della riga.


------------------------------------------------------------------------
5.5 INSTALLARE LE DIPENDENZE
------------------------------------------------------------------------

Con l'ambiente virtuale attivo:

   pip install -r requirements.txt

Il file requirements.txt contiene:

   Pillow>=10.0

Tkinter e SQLite sono già inclusi in Python e non vanno installati con pip.


------------------------------------------------------------------------
5.6 AVVIARE L'APPLICAZIONE
------------------------------------------------------------------------

Sempre con l'ambiente virtuale attivo e dalla cartella del progetto:

   python main.py

Si aprirà la finestra «Cosa Mi Metto?».

Se non vuoi attivare l'ambiente virtuale, puoi usare direttamente:

   .venv/bin/python main.py


------------------------------------------------------------------------
5.7 PRIMA ESECUZIONE
------------------------------------------------------------------------

Al primo avvio l'app crea automaticamente:

   data/armadio.db     → database SQLite
   data/foto/          → cartella per le copie delle foto

Vengono anche inserite le otto sezioni iniziali:
Maglie corte, Maglie lunghe, Pantaloni, Pantaloncini, Gonne, Scarpe,
Borse, Accessori.

Se vuoi fare una prova completamente pulita, fallo su una COPIA del
progetto: rinomina o elimina la cartella data/ e riavvia l'app. Verrà
ricreata da zero. Non farlo sull'originale se contiene dati che vuoi
conservare.


========================================================================
 6. PROVE DA FARE SU LINUX
========================================================================

Segui questo percorso per verificare tutte le funzioni principali.

PROVA 1 — Avvio
  - L'app si apre senza errori.
  - In alto si vedono le schede: Armadio, Aggiungi capo, Look, Idee, Diario.
  - In basso a destra compare il conteggio di capi e look.

PROVA 2 — Sezioni
  - Vai nella scheda «Armadio».
  - Crea una nuova sezione con «Nuova sezione».
  - Rinominala.
  - Prova a eliminarla: se è vuota deve sparire; se contiene capi deve
    comparire un messaggio di errore.

PROVA 3 — Aggiungere un capo con foto
  - Vai nella scheda «Aggiungi capo».
  - Premi «Scegli foto…» e seleziona un'immagine JPG o PNG.
  - Compila nome, sezione, colore, stagione e occasione.
  - Controlla che il ruolo nel look venga proposto in base alla sezione.
  - Salva.
  - Il capo deve comparire nella scheda «Armadio».

PROVA 4 — Foto non valida
  - Prova a scegliere un file che non è un'immagine (per esempio un .txt).
  - L'app deve mostrare un messaggio chiaro e non deve bloccarsi.

PROVA 5 — Ricerca e filtri
  - Nella scheda «Armadio» cerca un capo per nome o colore.
  - Prova il filtro per sezione.
  - Prova il filtro per stagione.
  - Premi «Azzera» e verifica che tornino tutti i capi.

PROVA 6 — Dettaglio, modifica ed eliminazione
  - Clicca su un capo: si apre la finestra con la foto ingrandita.
  - Premi «Modifica», cambia un dato e salva.
  - Apri di nuovo il dettaglio e premi «Elimina»: deve chiedere conferma.
  - Dopo l'eliminazione il capo deve sparire dall'armadio, dai look e dal
    diario.

PROVA 7 — Creare un look
  - Aggiungi almeno:
      una parte superiore,
      una parte inferiore,
      un paio di scarpe
    della stessa stagione.
  - Vai nella scheda «Look».
  - Scegli un capo per ogni ruolo.
  - Controlla l'anteprima con le foto affiancate.
  - Scrivi il nome del look e premi «Salva look».
  - Prova a caricarlo di nuovo con «Carica nel form».
  - Prova a eliminarlo.

PROVA 8 — Idee / Sorprendimi
  - Vai nella scheda «Idee».
  - Scegli stagione e occasione.
  - Premi «Sorprendimi».
  - Devono comparire parte superiore, parte inferiore e scarpe.
  - Se ci sono, devono comparire anche borsa e accessorio.
  - Premi di nuovo «Sorprendimi»: deve proporre capi diversi, se possibile.
  - Salva la proposta come look.

PROVA 9 — Diario
  - Vai nella scheda «Diario».
  - Controlla che la data sia quella di oggi.
  - Scegli un capo e premi «Segna come indossato».
  - Il capo deve comparire nell'elenco «Capi del giorno».
  - Prova a segnare di nuovo lo stesso capo nello stesso giorno: deve
    comparire un avviso.
  - Controlla le tabelle «Capi più indossati» e «Capi mai indossati».
  - Prova a rimuovere una voce dal diario.

PROVA 10 — Chiusura
  - Chiudi l'app con la X.
  - Riapri l'app: i dati devono essere ancora presenti.
  - Se il database resta bloccato, controlla che non ci sia un'altra
    istanza dell'app aperta.


========================================================================
 7. PROBLEMI COMUNI SU LINUX
========================================================================

ERRORE: "No module named tkinter"
  Soluzione:
    sudo apt install python3-tk          (Debian/Ubuntu)
    sudo dnf install python3-tkinter     (Fedora)
    sudo pacman -S tk                    (Arch)

ERRORE: "No module named PIL" oppure "ModuleNotFoundError: PIL"
  Significa che Pillow non è installato nell'ambiente virtuale.
  Soluzione:
    source .venv/bin/activate
    pip install -r requirements.txt

ERRORE: "No module named venv" oppure "ensurepip is not available"
  Soluzione:
    sudo apt install python3-venv        (Debian/Ubuntu)

ERRORE: "cannot open display" oppure l'app non si apre da terminale remoto
  Tkinter ha bisogno di un ambiente grafico. Non funziona su un server
  senza display. Avvia l'app dalla sessione grafica del computer Linux
  oppure usa il desktop remoto.

ERRORE: "database is locked"
  C'è probabilmente un'altra copia dell'app aperta.
  Chiudi tutte le finestre dell'app e riprova.

ERRORE: permesso negato su data/ o data/foto/
  Controlla i permessi della cartella:
    ls -l data
  Se necessario, assegna i permessi all'utente:
    chmod -R u+rwX data

ERRORE durante l'installazione di Pillow
  Aggiorna pip e riprova:
    python -m pip install --upgrade pip
    pip install -r requirements.txt


========================================================================
 8. RIEPILOGO RAPIDO DEI COMANDI LINUX
========================================================================

Da eseguire una sola volta:

  sudo apt install python3-tk python3-venv       (Debian/Ubuntu)
  cd ~/Progetto_Python
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt

Per avviare l'app ogni volta:

  cd ~/Progetto_Python
  source .venv/bin/activate
  python main.py

Oppure, senza attivare l'ambiente:

  cd ~/Progetto_Python
  .venv/bin/python main.py
